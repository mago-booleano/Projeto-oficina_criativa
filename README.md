# Feira de Oficinas Criativas

Sistema em TypeScript com programação orientada a objetos para gerenciar oficinas, instrutores e participantes.

## Como executar

1. Instale as dependências:
   npm install
2. Compile o TypeScript:
   npm run build
3. Inicie o servidor web:
   npm start
4. Abra no navegador:
   http://localhost:8000

## Funcionalidades

- Cadastrar oficina
- Cadastrar instrutor vinculando a uma oficina
- Cadastrar participante em uma oficina
- Listar oficinas
- Listar participantes por oficina

## Estrutura principal

- `index.html`: interface web
- `src/main.ts`: lógica do sistema e classes POO
- `src/styles.css`: estilo da interface
